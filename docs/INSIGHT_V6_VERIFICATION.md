# 인사이트 v6 재생성과 화면 검증

## 수정 내용

대량 리뷰 요약에서 `praise_label: 출퇴근 연결 안정성`처럼 입력 필드명이 문장에
노출된 문제가 있었다. 웹과 단일 HTML은 같은 저장 요약을 표시하므로 양쪽에 나타났다.

- 일반·분할 요약 프롬프트에서 장점의 **문자열 값만** 한국어 문장에 넣도록 명시했다.
- 요약·이슈·개선 제안에 내부 필드명이나 `label: 값` 표현이 있으면 형식 오류로
  거부한다. 대소문자·전각·Markdown 이스케이프와 `praise_lable` 오타도 검사한다.
- 실패한 요약 단계만 설정된 횟수 내에서 재시도한다. 성공한 근거 추출은 반복하지 않는다.
- 프롬프트 버전을 `review-insights-v6`으로 올려 기존 v5 결과의 캐시 재사용을 막았다.
  이전 프롬프트는 `evaluation/prompts/review-insights-v5*.txt`에 보존했다.

이슈·개선 제안·요약에서 내부 필드명 노출이 없음을 검사하고 원본 저장 JSON,
웹 인사이트와 단일 HTML에 같은 요약이 표시되는지 확인했다. HTML에서 배터리 주제를
펼쳐 리뷰 5의 원문 인용도 확인했다. 새 결과는 로컬 `output/final-tests/`에 저장하고,
이전 v5 JSON은 별도로 보관했다. 실행 산출물과 DB는 Git에 포함하지 않는다.

근거 개수는 기존 29개에서 37개로 바뀌었다. 원문은 동일하지만 AI 재추출에 따라
주제 표현과 묶음이 달라진 결과이며, 새로운 리뷰가 추가된 것은 아니다.
