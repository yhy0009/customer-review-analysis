# 45건 감정 라벨 사람 검토지

## 사용 방법

- 한국어 27건, 영어 9건, 한영 혼합 9건입니다. 자료의 원문은 기존 두 합성 평가셋에서 가져왔고, 답이 드러나지 않도록 ID와 순서를 바꿨습니다.
- **먼저 이 문서만 보고** 각 원문에 positive / neutral / negative 중 하나를 적고 판단 근거를 적으세요. 별점은 참고 정보입니다. 판단이 어렵다면 `보류`도 적으세요.
- 기대 라벨과 원본 ID가 있는 [평가 입력 JSON](development_45.v1.json), [출처 대응표](development_45_source_map.json)는 사람 라벨을 모두 적은 뒤 여세요.
- 이 45건은 AI 작성 개발용 합성 사례입니다. 크기를 늘렸어도 독립 시험 세트나 실제 고객 분포의 표본이 아닙니다. 사람 검토를 마치기 전까지 정답/정확도라고 부르지 마세요.
- 평가 입력 JSON SHA-256: `683c81b8478cc85dd62162fce6f60a9f5b8ebd711676cb4a9ec14de721aca829`. 모델 API 호출은 이 검토지 생성에 사용하지 않았습니다.
