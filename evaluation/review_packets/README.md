# 제품·영화 리뷰 품질 검토 자료

기존 사람 검토 후보는 **65건**입니다. 제품 리뷰 개발 사례 45건과 Cornell 영화 리뷰 20건을 합친 수치이며, 65건에 대한 모델 정확도를 뜻하지 않습니다. 추가 AI 호출 없이 자료를 구성했습니다.

| 자료 | 내용 | 라벨 상태 | 사람 검토지 |
| --- | --- | --- | --- |
| [제품 리뷰 45건](development_45.v1.json) | 한국어 27, 영어 9, 한영 혼합 9; 긍정·중립·부정 각 15 | AI 작성 개발용 초안, 사람 검증 전 | [블라인드 검토지](blind_45_human_labels.md) |
| [영화 리뷰 20건](cornell_movie_20_manifest.json) | Cornell 영문 문장, 긍정 10·부정 10 | 원본 Fresh/Rotten 자동 라벨, 사람 검증 전 | [로컬 블라인드 검토지](../../output/final-tests/cornell-movie-20/blind_movie_20.md) |

| [선행 모델 실행 6건](mini_review_2026-09-27.md) | 다국어 제품 리뷰 6건의 감정·요약·키워드·인사이트 | 초안 라벨과 비교했고 사람 판정 대기 | 같은 문서의 A·B·C 절 |

## 검토 순서

1. 각 블라인드 검토지의 **원문만** 읽고 사람 감정 라벨과 이유를 작성합니다. 중립이나 판단 보류도 허용합니다.
2. 작성 후 초안 라벨 또는 Cornell 원본 라벨을 엽니다. 영화 원문은 [Cornell 배포 자료](https://www.cs.cornell.edu/people/pabo/movie-review-data/)에서 가져왔고, 이 저장소에는 출처·선택 위치만 기록했습니다. 로컬 검토지는 `output/` 아래에 있어 Git에 포함되지 않습니다.
3. 제품 45건과 영화 20건의 일치율·오류 유형을 **따로** 봅니다. 영화 자료에는 원본 중립 라벨이 없고, 영문 영화 문장만 추렸습니다. 이 자료만으로 한국어 영화 리뷰나 전체 서비스 품질을 판단할 수 없습니다.
4. 현재 모델 결과는 [65건 평가 보고서](evaluation_65_2026-09-27.md)에서 확인합니다. 이 결과는 기존 임시 라벨과의 일치율입니다. 사람 라벨이 정리되면 그 라벨을 기준으로 다시 점수를 계산합니다.

## 입력 경로 확인

제품 CSV 40행과 영화 CSV 20행을 별도 시험 DB에 적재했습니다. 중복 2건을 제외한 raw 58건 중 의도된 오류 4건을 제외해 clean 54건이 되었고, 카테고리 비교에서 **영화 20건**이 별도 그룹으로 나왔습니다. 영화 20건은 제목과 별점 없이 본문만으로 통과했습니다. 이 입력 경로 확인 자체에는 AI 호출이 없었습니다. 이후의 감정 분석 실행은 위 65건 평가 보고서에 별도로 기록돼 있습니다.

영화 원본과 로컬 실행 자료: [검토지](../../output/final-tests/cornell-movie-20/blind_movie_20.md), [입력 CSV](../../output/final-tests/cornell-movie-20/movie_20_import.csv), [평가 JSON](../../output/final-tests/cornell-movie-20/movie_20_review_only.json). 평가기는 제목과 별점이 `null`인 영화 리뷰도 받을 수 있도록 수정했습니다.

## 소량 사람 확정 라벨 작업

[새 12건 검토 절차](HUMAN_REVIEW_12.md)와 [빈 라벨 입력 JSON](human_review_12.v1.json)을 제공합니다. 제품 6건은 기존 45건의 부분집합이고, 영화 6건은 제목이 있는 새로운 합성 사례입니다. 사람 검토 전에는 정답으로 사용하지 않습니다. `scripts/review_human_labels.py`는 미완료 라벨을 거부하고, 유형별 평가 입력 생성과 기존 실행의 오프라인 재채점을 지원합니다.

[도메인 수정 후 4건 확인](domain_fix_smoke_4_2026-09-27.md)은 이전 v7/v8 프롬프트의 소량 실행 기록입니다. 최신 버전의 전체 성능으로 해석하지 마세요. 이 문서의 `output/` 링크는 당시 실행한 컴퓨터의 로컬 자료이며 Git clone에는 포함되지 않습니다. 공유 가능한 입력은 이 폴더의 합성 JSON과 Cornell 출처 명세입니다.
