# 인사이트 v2 비교 결과 — 부분 개선, 품질 승인 대기

2026-09-13 실행 결과를 assistant가 원문과 대조했다. v2는 추가 검증에서 주요 증상을
더 구체적으로 보존했지만, 기존 세트의 누락은 해결하지 못했다. **전체 품질이 개선됐다고
판정하지 않는다.** 이 기록은 사람 검토를 대신하지 않으며 `narrative_review=pending`을 유지한다.

## 고정 조건과 재현 자료

- 라우팅 제공자 `openai-compatible`, 요청·응답 모델 필드 `gpt-5-mini`, 재시도 0.
- 감정 분석은 `review-sentiment-v1` 그대로다. JSON 스키마와 키워드 집계 규칙도 동일하다.
- 원래 18건 데이터, v1 프롬프트와 첫 실행은 변경하지 않았다.
- 추가 검증은 [실행 전 기준](VALIDATION_V1.md)의 9건을 고정했다. SHA-256:
  `d03a9814fbb8148987070dcf0c325e68888744f1e8f93f9daf4a0d2a6d636fad`.
- 두 비교 모두 저장된 감정·키워드를 재사용하고 사용자 입력 해시가 일치했다.
- 이번 요청은 총 14회: 추가 검증 10회(분류 9 + v2 요약 1), 기존·추가 세트 비교 각 2회.
  재호출로 좋은 응답만 선택하거나 실행 후 프롬프트·기대 라벨을 바꾸지 않았다.

합성 원문과 응답을 포함한 JSON 증거를 다음 경로에 보존했다. API 키는 포함하지 않는다.

| 자료 | 파일 |
| --- | --- |
| 원래 18건의 첫 실행 | [baseline-v1.json](results/2026-09-13/baseline-v1.json) |
| 추가 9건 전체 흐름 실행 | [validation-v1-v2.json](results/2026-09-13/validation-v1-v2.json) |
| 기존 18건 v1/v2 비교 | [comparison-reviews-v1.json](results/2026-09-13/comparison-reviews-v1.json) |
| 추가 9건 v1/v2 비교 | [comparison-validation-v1.json](results/2026-09-13/comparison-validation-v1.json) |

각 비교의 `source_sha256`은 위에 보존한 평가 JSON 파일의 바이트 해시다.
실행 시각·설정·프롬프트 원문·입력 해시·응답 모델과 지연은 JSON에 기록했다.

```bash
python scripts/compare_insights.py --live \
  --dataset evaluation/reviews.v1.json \
  --saved-evaluation evaluation/results/2026-09-13/baseline-v1.json \
  --output /tmp/cra-comparison-new-run
```

재현 시 내용과 지연은 달라질 수 있다. 현재 스크립트는 보존된 v1과 현재 코드의 프롬프트를
비교하므로 이후 프롬프트를 변경하면 이번 v2의 재현과 구분해야 한다.

이슈가 최대 3개라는 제약 아래에서 중요도 판단과 증상 보존이 충분히 안정적이지 않다.
단순히 특정 단어가 출력됐다는 이유로 의미적 품질을 자동 통과시키지 않았다.
후속 품질 검토에서는 리뷰별 근거와 선택·누락 사유를 추적하는 방식이 필요한지 명세부터
정하고, 사람이 검토한 새 사례와 반복 실행으로 확인하는 것이 남아 있다.

## 리포트 확인

TXT·Markdown 모두 ‘긍정 리뷰의 키워드’ / ‘부정 리뷰의 키워드’와 리뷰 전체 감정에 따른
집계 설명을 출력한다. 추가 사례 vp02의 `작동 소음=1`은 긍정 리뷰 목록에 그대로 남으며,
통계와 인사이트에서 같은 값을 표시한다. 기존 사례 p04의 `배송 지연=1` 역시 집계상 정상이다.
이는 키워드 자체의 감정 분석이나 주제 정규화를 새로 구현한 것이 아니다.

이 기록 당시에는 `AnalysisOptions.prompt_version="review-insights-v2"` 또는 `None`이 v2를
선택했다. 이후 근거·포괄성 검사와 제안 제한을 추가한 v4로 변경했다.
현재 적용 방법은 [추출 안내](../docs/INSIGHT_EXTRACTION.md), 후속 결과는
[v4 검증 기록](INSIGHT_V4_COMPARISON.md)을 참고한다. 이 문서의 과거 응답·판정은 유지한다.
